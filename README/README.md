# Project Documentation — Packaged Foods

## 1. Project Overview

This project analyzes packaged food products in India using Excel and Power BI to compare pricing and nutritional content across categories, helping identify healthier and more cost-effective choices.

## 2. Tools Used

- Microsoft Excel
- Power BI

## 3. Dataset

**Source:** `packaged_foods_india.csv`

**Data contains:** Item name, Brand name, Categories, Price, Calories, Carbohydrate, Proteins, Transfat, etc.

## 4. Steps Followed

- Cleaned data in Excel (e.g., removed blanks)
- Imported cleaned data into Power BI
- Built dashboard using charts and KPIs

## 5. Key Insights

1. Snacks and Instant food carry the highest sodium risk despite mid-range pricing.
2. Biscuits and Wafers are calorie-dense outliers.
3. Price does not correlate with nutritional content.
